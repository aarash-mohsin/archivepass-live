# ArchivePass · live page

The hosted, read-only page for **ArchivePass** on NEAR testnet: **https://aarash-mohsin.github.io/archivepass-live/**

- **Verify:** 14 PASS/FAIL checks computed in your browser from public NEAR testnet RPC
- **History:** every holder, contribution, keeper payout and missed period, from the asset's on-chain events
- **Fund:** add to the archive's upkeep with a NEAR testnet wallet (`fund_upkeep`)
- **Holder console:** a NEP-413 signed-message check that only the current NFT holder passes

This repository holds only the built static files. The source, contract and tests are in
[aarash-mohsin/archivepass-near](https://github.com/aarash-mohsin/archivepass-near) (`site/`, built with `npm run build:site`).
